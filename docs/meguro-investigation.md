# 目黒区「施設予約システム」調査メモ

- 調査日: 2026-11-23
- 対象: https://resv.city.meguro.tokyo.jp/web
- 結論: **空き状況の自動取得は実装していません。** 江戸川区と同じ理由で、サイトの robots.txt が空き照会のページへの機械的なアクセスを認めていないためです。

## 1. robots.txt

```
User-agent: *
Disallow: /*
Allow: /*.html
Allow: /*/*.html
Allow: /*/Home
Allow: /*/Wg_ModeSelect.aspx
Allow: /*/Wg_KoukyouShisetsuYoyakuMoushikomi.aspx
```

| パス | 判定 |
|---|---|
| `/web/Home`、`/Web/Home/WgR_ModeSelect`（トップページと検索の送信） | 許可 |
| `/Web/Yoyaku/WgR_ShisetsuKensaku`（施設・部屋の検索。空き照会の次の画面） | **不許可** |

許可されているのはトップページまでです。江戸川区の「えどねっと」と先頭5行が同じで、同じ系統のシステムと見られます。

## 2. 分かったこと

- 区のサイトには「空き状況の照会は、登録前の方も利用可能です」とあります。ログインなしの検索はトップページで受け付けられ、施設検索の画面へ進むところまで確認しました。その先は見ていません。
- 空き状況案内の閲覧は24時間。定期メンテナンスは偶数月の第4金曜 2:00〜2:30 です。
- 利用規約や区の案内に、機械的なアクセスについての記載は見つかりませんでした。
