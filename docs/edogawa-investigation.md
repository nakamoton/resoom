# 江戸川区「えどねっと」調査メモ

- 調査日: 2026-11-23
- 対象: https://www.shisetsuyoyaku.city.edogawa.tokyo.jp/user/
- 結論: **空き状況の自動取得は実装していません。** サイトの robots.txt が、空き照会のページへの機械的なアクセスを認めていないためです。

## 1. robots.txt

```
User-agent: *
Disallow: /*
Allow: /*.html
Allow: /*/*.html
Allow: /*/Home
```

| パス | 判定 |
|---|---|
| `/user/Home`（トップページ） | 許可 |
| `/user/Home/Search...`（施設検索の送信） | 許可 |
| `/user/AvailabilityCheckApplySelectFacility`（空き照会の次の画面） | **不許可** |

許可されているのはトップページと検索の送信までで、施設・部屋の一覧と空き状況はすべて不許可のパスにあります。設計書の方針（robots.txt に従う）により、ここで調査を止めました。

## 2. 分かったこと

- ログインなしでも、トップページの施設検索は受け付けられます。その先の空き照会の画面は確認していません。
- 画面の作りは ASP.NET Core と Vue です。検索の送信には、ページに埋め込まれた偽造防止トークンと Cookie が必要です。
- 利用者規約（令和8年1月12日改正）に、機械的なアクセスを名指しした条項はありません。関係しうる条項は次のとおりです。
  - 第9条2: 利用者番号とパスワードを第三者に譲渡・貸与できない
  - 第29条: システムを通じて得た情報を、私的利用の範囲を超えて使用できない（区の承認がある場合を除く）
  - 第31条: システムの運用を妨げる行為、システムの目的に反する行為などの禁止
- 抽選申込は毎月5日9時〜14日22時。空き予約の開始は、中央・小松川・葛西地区が毎月25日12時です。

## 4. 今後の選択肢

1. 区に問い合わせる。低頻度の空き照会が差し支えないかを確認します（トップページに問い合わせ先の記載があります）。
2. 手動で確認する施設として扱う。台帳にはリンクだけを置き、空き状況は各自がサイトで見ます。

区の了解が得られた場合は、2章の続きから調査を再開できます。
