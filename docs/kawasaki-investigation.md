# 川崎市「ふれあいネット」調査メモ

- 調査日: 2026-11-23
- 対象: https://www.fureai-net.city.kawasaki.jp/ （かんたん画面 `/web/`）
- 結論: **ログインなしで空き状況を取得できます。実装済みですが、既定では無効にしています。** 開発環境からは通しでの検証ができなかったためです（3章）。

## 1. 分かったこと

| 項目 | 結果 |
|---|---|
| ログインなしの空き照会 | できます。かんたん画面で、部屋ごとの空き状況まで進めます |
| robots.txt | ありません（404） |
| 文字コード | Shift_JIS |
| 受付時間 | 空き状況の照会は24時間（予約・抽選は7時〜24時） |
| 現行システムの終了 | 2027年3月12日17時。3月16日に新システムへ替わります。この日時以降、アダプタは問い合わせを送りません |
| 規約 | 「不正な手段でアクセスすること」を禁止。「安定的かつ公正な運用を妨げる恐れがある場合」はアクセスを遮断できる、とあります。リクエストの間隔は3秒にしています |

## 2. 問い合わせの流れ

| 順 | リクエスト | 返る画面 |
|---|---|---|
| 1 | `GET /web/index.jsp` | トップページ。Cookie が発行されます |
| 2 | `POST /web/rsvWTransInstSrchInstAction.do`（地域コード・館コード） | 施設選択（部屋の一覧） |
| 3 | `POST /web/rsvWInstSrchMonthVacantAction.do`（部屋の番号） | 1か月表示 |
| 4 | `POST /web/rsvWInstSrchVacantAction.do`（開始日・部屋の番号） | 指定日から7日間の空き状況（1部屋） |

- 空き状況は**部屋ごと・7日ごと**にしか取れません。1回の照会で送るリクエストは「3 + 部屋数 × 週数」です。
- ブラウザでは 2 の前に、予約メニュー・地域選択・館選択の3画面を通ります。アダプタはこれを省いています。
- 会館の指定は「地域コード-館コード」です（例: 中原市民館 = `14130504-1180`）。

## 3. 既定で無効にしている理由

**同じ訪問の途中で送信元のIPアドレスが変わると、画面遷移が続きません。** 同じ手順でも、前の画面に戻されたり、空の応答が返ったりします。

この開発環境は、リクエストごとに送信元のIPアドレスが変わります（10回で8種類を確認）。そのため、8施設を通しで照会すると6施設で失敗しました。失敗する位置は毎回違い、同じ施設が成功することもあります。

- 成功した照会（カルッツかわさき、麻生市民館、中原市民館の一部）では、結果は妥当でした。中原市民館 音楽室の1週間分は、ブラウザで見た画面と一致しています。
- 固定のIPアドレスから動かせば安定すると見ていますが、**未検証**です。省いた3画面が不安定さに関係している可能性も残っています。
- 同じ系統の品川区のシステムは、同じ環境でも安定して動きました。そのため、IPアドレスだけが原因とは言い切れません。

本番で使うには、固定のIPアドレスから外に出る構成（Google Cloud なら Cloud NAT）が必要です。検索コマンドでは、明示的に指定したときだけ使います。

```bash
pnpm availability --adapters kawasaki --municipality 川崎市 --from 2026-12-12 --to 2026-12-18
```

## 5. 照会できる範囲

2026-11-23 時点で、中原市民館 音楽室は2027年3月31日まで空き状況が出ました。それより先を指定すると、エラーにはならず、全コマが「受付期間外」で返ります。アダプタは、全コマが受付期間外の週に入ったところで止まります。

「空き」は「予約が入っていない」という意味で、「今すぐ予約できる」とは限りません。現行システムが止まる3月12日より後の日も「空き」と表示されます。
