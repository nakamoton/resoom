# 江東区（江東区文化コミュニティ財団）「施設予約・講座管理システム」調査メモ

- 調査日: 2026-11-23
- 対象: https://sisetun.kcf.or.jp/web/ （区の文化センター等。森下文化センターを含む）
- 結論: **ログインなしで空き状況を取得できる見込みです。まだ実装していません。** robots.txt はなく、利用規約にも機械的なアクセスを禁じる定めはありません。川崎市と同じ系統のシステムですが、画面の順路を飛ばせない点が違います（3章）。

## 1. 区と財団の案内

- 江東区の文化センター（江東区文化センター・森下・古石場・豊洲・亀戸・東大島・砂町、総合区民センター、ティアラこうとう、資料館）は、公益財団法人江東区文化コミュニティ財団が管理し、財団の「施設予約サービス」で予約します。区のスポーツ施設や区民館の予約システムとは別です。
- 財団の案内（https://www.kcf.or.jp/yoyaku/shisetsu/ ）に「施設の空き状況照会（どなたでも空き状況の照会はできます。）」とあります。予約・抽選申込みは窓口で利用者登録をした人だけです（インターネットからは登録できません）。

## 3. 問い合わせの流れ（確認できたもの）

画面の順路を飛ばすと「遷移情報に誤りがあります。再度、認証を行って下さい。」と返ります。川崎市のアダプタのように途中の画面を省くことはできず、順にたどる必要があります。

| 順 | リクエスト | 返る画面 |
|---|---|---|
| 1 | `GET /web/index.jsp` | Cookie（JSESSIONID）が発行されます |
| 2 | `POST /web/rsvWTransUserAttestationAction.do`（`displayNo=pawaa2000`） | メニュー画面（ログインなし） |
| 3 | `POST /web/rsvWTransInstSrchVacantAction.do`（`pawab2000`） | 空き状況の検索（検索方法の選択） |
| 4 | `POST /web/rsvWTransInstSrchAreaAction.do`（`prwaa1000`、地域から） | 地域の選択（江東区 = `1010`） |
| 5 | `POST /web/rsvWTransInstSrchBuildAction.do`（`prwbb1000`、地域 `1010`） | 館の選択（森下文化センター = 館 `1050`・順番 `5`） |
| 6 | `POST /web/rsvWInstSrchMonthVacantAction.do`（`prwbb2000`、館 `1050`） | 館の1か月表示（日ごとに「一部空き」「予約あり」など） |
| 7 | `POST /web/rsvWInstSrchVacantAction.do`（`prwmn1000`、日付、`transVacantMode=7`） | その日の館の全部屋の空き状況（午前・午後・夜間） |

- 7 の画面は、1日分・館の全部屋です。部屋ごとに午前・午後・夜間の状態が画像の `alt`（「空き」「予約あり」「休館日」「保守日」「期間外」など）で入っています。森下文化センターの AV・ホールは部屋番号 `1050030` です。
- 凡例に「音出予約」という区分があります。音を出す利用の予約を示すと見られますが、意味は未確認です。
- 1回の照会で送るリクエストは「6 + 日数」の見込みです。1か月表示から翌月へ進む操作（`moveCalender`）もあります。

この開発環境は送信元のIPアドレスがリクエストごとに変わりますが、順路どおりに進めた3回とも、7の画面まで問題なく進めました（川崎市で起きた、途中で画面遷移が切れる問題は出ていません）。

## 4. 施設の予約ルール（財団の案内から）

- 予約はインターネットで、受付開始日（毎月3日、1月は6日）の13時から利用日の7日前まで。取消は利用日の14日前までインターネットで。
- 抽選申込は毎月20日〜翌月1日（1月は4日）の23:59まで。結果は3日（1月は6日）9時に公開。
- 支払いは予約から14日以内に窓口で。過ぎると自動で取消。
- 森下文化センターの多目的ホール・第2レクホールはインターネットで予約できず、窓口・電話のみ（空き照会はできます）。AV・ホールはインターネットで予約できます。
- 休館は毎月第1・3月曜（祝日は開館）と12月29日〜1月3日。

## 6. 実装するときの方針（案）

- 川崎市のアダプタ（同じ系統）の解析を下敷きに、順路どおりにたどる別のアダプタとして作る。
- 日ごとの館の画面から、台帳の部屋の行だけを読む。1か月表示で「空き」のない日は、日ごとの画面を開かずに済ませて、リクエストを減らす。
- 間隔は3秒、3:00〜4:00 は問い合わせない。

## 7. 残っていること

- 「音出予約」の意味
