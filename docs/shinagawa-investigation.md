# 品川区「施設予約システム」調査メモ

- 調査日: 2026-11-23
- 対象: https://www.cm9.eprs.jp/shinagawa/web/
- 結論: **ログインなしで空き状況を取得できます。実装済みで、既定で有効です。** robots.txt は取得できませんでしたが（1章）、楽団の判断で有効にしました。

## 1. robots.txt が取得できない

`https://www.cm9.eprs.jp/robots.txt` は、3回試して3回とも **サーバーエラー（502）** でした。ファイルの内容は確認できていません。

- このサーバーは複数の自治体が共用しており、`/shinagawa/web` 以下だけが実際のシステムにつながっています。サーバー直下の `/favicon.ico` も同じ 502 になるので、robots.txt がそもそも置かれていないように見えます。
- 空き状況のページには、検索エンジン向けの制限（`meta robots`、`X-Robots-Tag`）もありません。
- サイトや区の案内に、機械的なアクセスについての記載は見つかりませんでした。

一方で、厳格な解釈では「サーバーエラーで取得できない間はアクセスを控える」という読み方もあります。

この点を楽団で検討し、2026-11-23 に**既定で有効にする**と決めました。robots.txt が取得できるようになった場合は、内容を確認し直します。

## 3. 問い合わせの流れ

| 順 | リクエスト | 返る内容 |
|---|---|---|
| 1 | `GET /index.jsp` | トップページ。Cookie が発行されます |
| 2 | `POST /rsvWOpeUnreservedSearchBuildAjaxAction.do`（地区と館） | 部屋の一覧 |
| 3 | `POST /rsvWOpeInstSrchVacantAction.do`（利用目的など） | 空き状況の検索結果の画面 |
| 4 | `POST /rsvWOpeInstSrchVacantAjaxAction.do`（部屋・開始日） | 指定日から7日間の空き状況（1部屋） |

- 1回の照会で送るリクエストは「3 + 部屋数 × 週数」です。
- 利用目的の指定が必須で、**楽器演奏**で照会しています。この目的で出てくる部屋は音楽室だけです。
- 会館の指定は「地区コード_館コード」です（中小企業センター = `1400_2400`）。

## 4. 照会できる範囲

2026-11-23 時点で、2027年3月31日まで空き状況が出ました。それより先は全コマが「受付期間外」で返ります。当日のコマも「受付期間外」です。

「空き」は「予約が入っていない」という意味です。3月分はまだ抽選の申込期間中ですが、「空き」と表示されます。

優先団体は、中小企業で働く勤労者と小規模事業主の団体です。休館は毎月第4日曜と12月29日〜1月3日です。
