## 1. 分かったこと

| 項目 | 結果 |
|---|---|
| ログインなしの空き照会 | できます。トップページに「ログインせずに空き状況を検索」があり、ゲストとして照会画面まで進めます |
| 画面の作り | サーバー側で生成されるHTMLです。ブラウザの自動操作は不要で、通常のHTTP通信で取得できます |
| 必要なリクエスト数 | 1会館・1か月分で4回（セッション開始、会館検索、部屋選択、31日間表示）。以降は1か月ごとに1回 |
| 同時に選べる部屋 | 画面上は、同じ会館の複数の部屋を1回で選べます。アダプタも対応していますが、実サイトで試したのは1部屋ずつです |
| robots.txt | ありません（404） |
| 受付時間 | 5:00〜翌1:59。時間外は問い合わせない実装にしています |
| ログイン時の画像認証 | 今回はログインしていないため未確認です |
| システム内の利用規約 | ゲストの画面遷移では表示されませんでした。未確認です |

## 2. 画面遷移

| 順 | リクエスト | 主な送信項目 | 返る画面 |
|---|---|---|---|
| 1 | `GET /menu/Welcome.cgi` | — | トップページ。セッションCookieが発行されます |
| 2 | `POST /menu/Login.cgi` | `action=Search`, `loginBtn=1`, `optYoyakuMode=0`, `chkSearchItemsKaikan=会館コード` | 施設絞り込み（部屋の一覧と定員） |
| 3 | `POST /yoyaku/ShisetsuMultiSelect.cgi` | `action=Enter`, `checkMeisaiUniqKey=部屋の識別子`（複数可） | 空き照会（当日から7日間） |
| 4 | `POST /yoyaku/CalendarStatusSelect.cgi` | `action=Setup`, `optYear`/`optMonth`/`optDay`, `radioshow=month` | 空き照会（指定日から31日間） |

利用者番号やパスワードは送りません。

## 3. 空き状況の表示

コマは部屋ごとに違います（例: 大田区民プラザ 第一音楽スタジオは 09:30-11:30 など5コマ、文化センターの集会室は 09:00-12:00 / 13:00-17:00 / 18:00-22:00 の3コマ）。

| アイコン | 画面の凡例 | resoom での状態 |
|---|---|---|
| `icn_scche_ok` | 空き有り | `available` |
| `icn_scche_noset` | 予約済み | `reserved` |
| `icn_scche_out` | 予約申込対象外 | `not_bookable` |
| `icn_scche_rest` | 休館日 | `closed` |
| `icn_scche_hoshu` | 保守点検 | `maintenance` |
| `icn_scche_uten` | 利用中止 | `suspended` |
| `icn_scche_haifun` | 利用不可 | `unavailable` |

## 4. 照会できる範囲

先着予約がまだ始まっていない月は照会できません。その期間を開始日に指定すると、サイトはエラーを出さず、**直前の表示をそのまま返します**。アダプタは、返ってきた表の開始日が指定と違うことでこれを検知して止まります。

2026-11-23 時点の実測:

| 施設 | 照会できた範囲 | 公式ルールとの対応 |
|---|---|---|
| 大田区民プラザ | 2027年3月3日まで（3月1〜3日は「予約申込対象外」） | 集会施設: 3月分は抽選申込中、先着は12月9日から |
| 池上・嶺町文化センター | 2027年1月31日まで | 文化センター: 2月分は二次抽選の申込中、先着は12月9日から |

## 5. 予約ルール（公式ページから）

出典: [うぐいすネット利用案内](https://www.city.ota.tokyo.jp/shisetsu/uguisunet_annai/ugu.html)、[音楽スタジオの利用予約等がうぐいすネットに切り替わります](https://www.city.ota.tokyo.jp/shisetsu/uguisunet_annai/music_studio.html)

| | 集会施設 | 文化センター |
|---|---|---|
| 抽選申込 | 利用月の4か月前の16日〜末日 | 一次: 4か月前の16日〜末日。二次: 3か月前の16日〜末日 |
| 抽選日 | 申込月の翌月1日 | 同じ |
| 結果確認・確定 | 2日〜7日（1月は4日から）。**確定処理をしないと当選無効** | 同じ |
| 支払い（抽選分） | 利用月の3か月前の15日まで | 結果確認後、同月15日まで |
| 先着予約 | 3か月前の9日から、利用日の3日前まで | 二次抽選の結果確認月の9日から |
| 支払い（先着分） | 予約日から14日以内 | 未確認 |
| キャンセル待ち | 3か月前の16日8:30から、利用日の6日前まで | 未確認 |
| 抽選の上限 | 1登録で6コマ | 一次4コマ（当選2コマ）、二次と合わせて5コマ |

12月の申込期間は28日までです。文化センターの抽選は「対象となる団体」向けと書かれており、個人登録で申し込めるかは未確認です。大田区民プラザが集会施設のルールに当たることは、照会範囲の動きが一致することからの推定です。

## 6. 会館コード

| 会館 | コード |
|---|---|
| 大田区民プラザ | `131113_001_18` |
| 大田文化の森 | `131113_001_17` |
| 大田区民ホール・アプリコ | `131113_001_19` |
| 池上文化センター | `131113_001_24` |
| 嶺町文化センター | `131113_001_25` |

部屋の識別子は会館コードに枝番が付いた形です（例: 大田区民プラザ 第一音楽スタジオ = `131113_001_18_11_01`）。アダプタは会館検索の結果から部屋名で引くので、台帳には会館コードと部屋名だけを持たせています。

施設検索のカテゴリには「音楽室」「スタジオ」「リハーサル室」があります。打楽器可の候補を広げるときの入口になります。

## 7. 試し方

```bash
pnpm install
```

```bash
pnpm ota:search --from 2027-01-01 --to 2027-03-31 --days sat --dates 2027-01-16,2027-02-20
```

対象の部屋は `data/seed/ota-rooms.json` にあります。1回の実行で送るリクエストは、会館ごとに4〜6回です。2秒間隔で直列に送ります。
