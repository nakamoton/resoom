# 文京区「『文の京』施設予約ねっと」調査メモ

- 調査日: 2026-11-23
- 対象: https://www.shisetsu.city.bunkyo.lg.jp/
- 結論: **空き状況の自動取得はできません。** 江戸川区・目黒区と同じく、サイトの robots.txt が空き照会のページへの機械的なアクセスを認めていないためです。

## 1. robots.txt

```
User-agent: *
Disallow: /*
Allow: /*.html
Allow: /*/*.html
Allow: /*/Home
```

| パス | 判定 |
|---|---|
| `/`、`/user/Home`（トップページ） | 許可 |
| `/user/` 以下のそのほかの画面（施設の検索、空き照会） | **不許可** |

江戸川区の「えどねっと」の robots.txt と1文字も違いません。設計書の方針（robots.txt に従う）により、許可されているトップページを1回開いたところで調査を止めました。

## 2. 分かったこと

- 区の案内（施設予約システム「『文の京』施設予約ねっと」の利用について）に、空き状況の確認は「どなたでもご覧いただけます」、予約には事前の利用登録が必要、とあります。人が画面で見る分には問題ありません。
- 画面の作りは江戸川区と同じ ASP.NET Core と Vue です（偽造防止トークンと Cookie を使う）。同じ系統のシステムと見られます。
- 2026年3月の機能改修で、同じ利用者IDで複数の端末から同時にログインできなくなっています。
- 対象は区の主な集会施設、アカデミー施設（アカデミー湯島など）、シビックホール・スカイホール、スポーツ施設です。

## 3. 楽団が使った部屋

| 台帳の部屋 | 定員 | 料金（区のサイトの一覧） |
|---|---|---|
| アカデミー湯島 視聴覚室 | 56人 | 午前 2,500円・午後 3,200円・夜間 2,500円 |

開館は9:00〜21:30、休館は12月29日〜1月3日です。申込みはアカデミー湯島の窓口、文京シビックセンター2階の文京アカデミー事務室、または予約ねっとです。

## 4. 検索ページでの扱い

- 「自動で検索していない自治体」の理由は、江戸川区・目黒区と同じ「予約サイトが機械的なアクセスを認めていません（robots.txt）」にしました。
- 予約サイトへのリンクを付け、人が確認できるようにしています。
